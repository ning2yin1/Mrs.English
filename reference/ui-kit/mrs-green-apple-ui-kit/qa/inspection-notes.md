# 検査メモ

117論理素材をasset-check-01〜06の6枚で、暗色背景と明色背景の両方に合成して目視検査した。カード4枠は別途大きく表示して比較した。主要画面は納品部品で再構成し、生成モックアップとの差異を文章に整理した。

## 修正した点
- 初回カード整形の分割継ぎ目を除き、連続した質感＋共通窓マスクへ変更。
- 配置図の埋め込み画像参照を修正し、パネル/フレーム/アイコンが実際に描画されることを確認。
- PLAY配置図から答え全文のヒントを除き、NORMAL/HARDを途中回答状態に変更。使用済み語をbankから除き、CHECKを追加。
- 端のaurora装飾を弱め、設問近くの強い線を抑制。
- アイコンPNGを96×96へ書き出し、SVG24×24と区別して一覧に記録。

## 判定
- 全117PNGにalpha0の実透過ピクセルがある。疑似チェック柄背景は見られない。
- 全4カードの外寸600×840、写真窓の内側でalpha0を確認。中心だけの1点確認ではなく、角丸内側の面領域全体を走査。
- 透明な光は暗色/明色の両背景で境界に黒いマットが見られない。
- 全素材の寸法、参照ファイル、SVG構文、ファイル名の小文字/ハイフン規則を検査。
- 文字入りの実装用画像は、ユーザーが差し替えられるよう分離した仮タイトルロゴ文字だけ。ラベル類は無文字。

## 使用時の注意
淡いアイコンや白いロゴは明色の写真に直接重ねると弱くなる。濃紺パネル/scrimを介して使うこと。大きいUI面を写真上に置く場合はCSSのbackground opacityを調整し、明るい写真でも読める状態へ寄せる。
未添付写真の顔位置、実機でのsafe area、キーボード、操作、保存、音声、動作速度は未検証。検査結果は静止素材に対するものである。
