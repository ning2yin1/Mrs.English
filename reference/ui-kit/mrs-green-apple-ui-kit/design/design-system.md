# GREEN ROOM ENGLISH — Design system v1

仮称：GREEN ROOM ENGLISH。タイトルは正式決定ではなく、テキスト差し替えを前提とする。Mrs. GREEN APPLEファン向け個人利用PWAのオリジナルUI。ゲーム本体・写真・音声・問題データは本パッケージに含めない。

## ビジュアル方針
写真が主役。濃紺のガラスにシルバーの細い面取り、ミントの光を添える。装飾は画面の端に寄せ、英文の背後を暗くする。色と形の両方で状態を伝える。公式ロゴ・公式アプリを複製しない。

## 書体とサイズ
日本語：-apple-system, BlinkMacSystemFont, 'Hiragino Sans', 'Noto Sans JP', sans-serif。英語：同システムsans。数字はtabular-nums。外部フォント通信不要。ロゴのみGeorgia系serif＋広い字間のsans副題を推奨。
論理基準844×390 CSS px。本文16–18、設問18–22、見出し22–26、補助12–14、ナビ11–12、スコア38–48px。長い日本語を画像に焼かない。縮小で収めず折り返し・内部スクロール。

## 形・質感
パネル角丸16、ボタン12、単語タイル10、ステータスバー・ゲージ999px。枠1px、ハイライト1px。濃紺パネルopacity 0.82–0.94、文字opacity 1。写真に合わせて局所scrimを増やす。backdrop-filterは最大2面、使えない場合#101E32の94%で代替。大きな黒影や輪郭の多重発光を避ける。
ボタンは44px以上の当たり判定、主ボタン48px高、押下translateY(1px)、disabledは彩度とopacityを落としラベルも併記。タイル最小44px高、選択色だけでなく縁・チェックで示す。

## アイコン
24×24 viewBox、線幅1.7、round cap/join、無文字。白系の単色。表示20–24px、当たり判定44×44px。選択時の色はCSS maskでmintへ。全タブ同一線幅。GPとハートのみ意味を持つアクセント色。

## カード
外寸600×840（5:7）。写真窓x=30,y=30,w=540,h=750、角丸18。全ランク共通。写真のobject-positionはカードIDごとに保持。フレームを変更しても写真座標を変更しない。下部60pxにラベルをDOMで重ねる。C=直線銀、B=二重青、A=菱形紫、S=金＋ホログラム弧。ランク字形はDOM、枠自体には文字なし。

## アニメーション
タブ160ms、ボタン100ms、パネル220ms、正解450ms、誤答180ms（赤い縁のみ）、報酬800ms。ガチャ通常900ms/A1500ms/S2200ms。Sは虹色リング→カード→粒子、白フラッシュは最大opacity .12で一度だけ。連続点滅なし。prefers-reduced-motionではフェード120ms＋静止枠に置換。音声は操作後のみ。CSS opacity/transform中心、Canvas粒子は上限40個。

## 可変レイアウト
100dvw×100dvhとsafe-area-inset-*を利用。844×390は安全領域込みの仮基準。左右safe inset＋12px、上8px、下safe inset＋8px。下ナビ56px、上48px、隙間8pxを優先。写真cover、焦点座標を別データ化。横幅が足りない時は二列を維持したまま補助説明を畳む。bodyスクロール禁止、リストだけ内部スクロール。
MASTERはキーボード出現時にVisualViewportの高さへ追従し、ナビ・装飾を畳んで設問と入力を優先。Safariで横向き固定が保証される前提にせず、縦画面には端末回転案内を置く。

## 制作一覧と順序
1. 共通：ナビ背景、選択線、通知、パネル、ボタン、モーダル、状態枠、統一アイコン。
2. 主要6画面のモックアップ：HOME / PLAY / RESULT / CARDS / GACHA / CHAT。写真なしの抽象領域は配置確認用。
3. タイトル：無文字ロゴ装飾・start装飾・光。HOME：ステータス・壁紙枠・選択枠。
4. PLAY：文法リスト・難易度4種・クリア・評価・設問・回答・タイル・解説・進捗。
5. RESULT：結果装飾・評価メダル・GP・好感度・ゲージ。
6. CARDS：同一窓の4枠・未所持・詳細・一覧装飾。
7. GACHA：背景重ね・ボタン・カード裏・出現通常/A/S・10連枠。
8. CHAT：行・吹き出し送受信・未読・ロック・解放。
9. LOGIN：画面装飾・日枠・今日・獲得。SETTINGS：パネル・slider・switch・dialog。
10. PNG/SVGの実ファイル検査、一覧表・配置/アニメーション指示・ZIP。

伸縮可能なUIはSVGを正本としてPNGも同梱。高級な光の質感は画像生成PNGを別レイヤーに置く。装飾と動的テキストは分離。モックアップ内の文字・数値はサンプルで、ゲーム仕様値ではない。
