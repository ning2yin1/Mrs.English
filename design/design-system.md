# アートディレクション

Cosmic Botanical Pop。夜の宇宙、植物と果実、乳白の紙、透明なガラス、多彩な光を組み合わせる。白い余白と写真を見せる面積を守る。緑だけで染めない。写真を隠す濃紺パネルは追加しない。

|役割|色|用途|
|---|---|---|
|Emerald|#00C88A|主操作・選択|
|Sky|#16BDF0|NORMAL・補助操作|
|Pink|#FF63B7|好感度・新着|
|Violet|#B477F5|HARD・A|
|Sun|#FFD65B|MASTER・報酬|
|Ink|#16382E|淡色上の文字|
|Paper|#FFF9ED|設問・説明|

角丸は小部品12〜18px、大部品24px、主要ボタンは丸みの強いカプセル。タイトル20〜28px、本文16〜19px、補助12〜14px。タッチ領域44px以上。ボタン文字は太字。濃色文字を多色タイルへ、白文字を濃い主操作へ。写真窓以外の小さな装飾は文字をまたがない。

HOMEは既存写真、文法は夜、RESULTは白金と虹、GACHAは紫とプリズム、CARDSは淡いラベンダーのギャラリー、LOGINは昼の庭園、CHATは縦長の乳白、初回/設定は光の温室。bg-onboardingは設定と共用する静かな背景、全画面使い回しではない。PLAYはHOME写真を再利用してよい。

mockupsは同じ個別部品で合成した正確な配置参考。人物は未添付のため写真枠。前回試作の完全な元画像は今回参照できないので、現在残っている生成背景と採用された文章上の方向から再設計している。商用ゲーム品質という目標に対して最終の写真・日本語・実機組み込み後の調整は別途必要。
