# Mrs.English

写真・カード収集と英語学習を組み合わせた、iPhone横画面向けの非公式・個人用PWAです。Vite / React / TypeScriptで実装しています。バックエンドやAPIキーは不要です。

## 起動

Node.js 22.12以上（この環境では24.19.0）で、既存のチェックアウトを使用してください。

```sh
cd /workspace/Mrs.English
npm ci
node scripts/prepare-assets.mjs
npm run dev
```

ローカルの開発サーバーを起動します。PWA・Service Workerを検証する場合は `npm run build` 後に `npm run preview` を使用してください。配信ベースパスは `/Mrs.English/` です。HTTPSまたはループバックのセキュアコンテキストが必要です。

`prepare-assets.mjs` は正規化済みの `assets/photos`・`assets/audio` と、使用するUI部品のみを `public/assets` にコピーします。人物素材のコピー先と `dist` はGit管理から除外しています。`reference/user-original` は配信しません。

## 実装済みのゲームルール

- 60文法 × 各10問、4難易度。制限時間・スタミナ・GP回数制限なし。
- EASY：文法・和訳に合う4択穴埋め。NORMAL：単語並び替え。HARD：ダミー語3つを追加。MASTER：英文入力。
- 正解100点、S=10正解 / A=8–9 / B=6–7 / C=0–5。
- 正解ごとに10 / 15 / 20 / 30 GP。完走ボーナスは今回の依頼を優先し追加しません。
- 選択メンバーの好感度は正解数、全問正解時はさらに5。メンバー別に保存。
- 1回300GP、10連2,700GP。C60% / B25% / A12% / S3%。10連の最初の10枚すべてがC/Bなら最後の1枚をA/S=80/20で置換します。この保証のため、10連全体の最終分布は単発の基礎確率と異なります。
- カード79種、重複は枚数を記録。育成・合成・デッキなし。
- 創作チャットは3人 × 15会話。好感度0 / 20 / 50 / 100 / 200で解放。本人の発言・リアルタイム返信ではありません。
- ローカル日付で1日1回、7日循環のログイン報酬。50 / 60 / 70 / 80 / 90 / 100 / 200 GP。過去日付への変更による再受領を防止します。完全オフラインのため、悪意ある端末時計変更へのサーバー側検証はありません。
- 文法3項目ごとに背景を切替。ホームは独立して20枚から選択。
- WAV16本は `data/assets.json` の音声ID→写真カードIDで対応。同じ音声の連続選択を避け、成績ランクと独立に抽選します。画面遷移で停止、再生・停止操作あり。
- BGMは未同梱。設定から自分の音声を端末内に追加可能。BGM・効果音・メンバー音声の音量は独立。

## データと教材の保守

`data/questions-600.json` が教材の正本です。`data/grammar-topics.json` は文法と背景・設問の対応、`data/mode-overrides.json` は600問分の明示的な穴埋め位置・誤答3つ・HARD用ダミー語です。実行時のランダムな単語置換は行いません。

EASYは画面に表示する**和訳と文法項目に合う**語を選びます。時制や接続詞には、別の意味なら文として成立する誤答も含みます。日本語・学習対象の文法との整合性を判断基準とします。NORMAL/HARDは重複語を固有IDで管理し、組み立てた表層文で採点します。MASTERは大小文字・連続空白・末尾句読点・曲がったアポストロフィを正規化し、登録済みの自然な別解を受け入れます。意味を推測して未登録のあらゆる言い換えを許容する仕組みではありません。

実装時に全600英文と対象語を確認し、borrowの和訳、結果のto不定詞の解説、過去完了の解説などを修正。短縮形・一部の節順変更を明示的な別解として追加しています。独立した英語母語話者・教育専門家による最終監修が完了したという意味ではありません。発展内容は発展と表示します。

音声ごとの表示写真は `assets.json` の `audio[].resultPhotoCardId` を変更します。同じメンバーかどうかはテストで検証します。写真は縦横比を保つ `contain` で人物を切らずに表示し、枠の写真窓座標は全レア度共通です。写真の好み・セリフに合う表情は必要に応じて差し替えてください。

## 保存・オフライン

ゲームデータはIndexedDBのトランザクションで保存。途中回答・解説状態も再開でき、報酬は同じセッションに一度だけ加算します。直前の正常データも保存し、破損時の復旧を試みます。復旧不能時はJSON復元または明示的な初期化が必要です。保存失敗を成功表示しません。

設定からJSONエクスポート／検証付きインポートが可能です。復元は既存データを置換する前に確認します。バックアップには写真・WAV・追加BGMは含めません。ブラウザやOSによるストレージ削除に備えて定期的に書き出してください。

アプリシェル・教材・使用UIはビルド時にバージョンを付けてプリキャッシュ。大きな写真・音声は使用時にランタイム保存し、設定の「写真・音声をオフライン保存」で全115ファイル（約26MB）を明示的に保存できます。未保存の素材はオフラインでは取得できません。新しいアプリはユーザーが設定から更新を適用するまで待機します。

## 検証

```sh
npm test                 # 600問×4モード、240完走、報酬、確率、保存検証
npm run audit:data       # 件数と参照検証をdata/implementation-validation.jsonへ
npm run build            # 型検査と本番ビルド
PLAYWRIGHT_BROWSERS_PATH=/workspace/.mrs-browsers npm run test:e2e -- --project=chromium
bash scripts/setup-webkit.sh   # このDebian 13クラウド環境用の初回準備
npm run test:webkit           # 共有ライブラリの実ロード確認後にWebKitを実行
```

システムの `/usr/bin/chromium` がある場合は自動利用します。別の実行ファイルは `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` で指定できます。Chromiumのみの実行は `npm run test:e2e -- --project=chromium`。WebKitの取得にはPlaywrightの配布ドメインへのネットワーク許可が必要です。このクラウド環境では許可の反映を確認済みです。

`setup-webkit.sh` は公式Debianの署名付きメタデータとパッケージハッシュをAPTで検証してから、不足ライブラリを `/workspace/.mrs-system` へ展開します。sudoは不要で、システム全体のライブラリやWebKitの実行ファイル・ラッパーは書き換えません。公式MiniBrowserが使用する検索ディレクトリには、不足するライブラリへのリンクだけを追加します。

Playwrightの一部の依存検査はシステムのldconfigキャッシュだけを見るため、作業領域のライブラリを検出できません。`test:webkit` は6ライブラリの実際の動的ロードを検査してから、この事前検査のみを置き換えてブラウザを起動します。署名・ハッシュ・TLS検証、ブラウザ起動、機能テストの検証は省略しません。

E2Eは4難易度の完走、誤答・解説保持、再開、10連保証とスキップ、カード、チャット既読、JSON復元、ログイン二重受領防止、オフライン再読み込み、667×375 / 844×390 / 852×393 / 932×430の6タブ、全写真・WAVのHTTP応答を検証します。画像・音声のデコードも別途確認しています。

iPhone実機のSafariとホーム画面起動、ノッチ左右、システムキーボード、OSの音声制約・ストレージ回収は実機での最終確認が必要です。デスクトップWebKitの検証は実機試験の代用にはなりません。詳しい実行結果は `docs/IMPLEMENTATION-REPORT.md` を参照してください。

## 公開について

**この作業は公開デプロイを行いません。** GitHub Actionsによる自動公開も設定しません。人物写真・WAVを新たにコミットしたり、GitHub Pagesなどへ配信する前に、ユーザーの明示的な確認が必要です。既に提供元コミットに含まれていた素材について、この実装作業で公開許可を得たとはみなしません。

ビルド成果物 `dist` にはローカル検証のため人物素材が含まれます。承認前にアップロードしないでください。公開用に人物素材を除き、端末内インポート方式へ変更する場合は別の公開仕様として実装・検証してください。
