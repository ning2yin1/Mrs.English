# Mrs.English 実装・検証レポート

2026-10-25。作業ブランチ：`feat/mrs-english-pwa`。

## 実装範囲

タイトル、HOME / PLAY / CARDS / GACHA / CHAT / SETTINGS、ログイン報酬、解答・解説・リザルト、ガチャ演出、カード詳細、壁紙選択、保存確認を実装。画面の文字と操作はDOMで、UIキットのアイコン・カード枠・光素材を組み合わせています。画面全体のモックアップを貼る方式ではありません。

学習は全60文法・600英文、4難易度。10問を無制限に繰り返し、正解ごとにGPを獲得できます。GP・ガチャ価格・保証・好感度は今回の依頼文を優先して旧仕様から変更しています。完走ボーナス・スタミナ・育成・デッキは追加しません。

カード79種、背景20枚、WAV16本を提供素材のままローカルに組み込み。音声ごとに写真カードIDを指定し、同じメンバーであることを検査。評価と音声は独立で、連続する同一音声を避けます。写真の切断を避けるため表示はcontainを採用し、枠と窓座標は全レア度で共通です。

チャットはメンバーごとに15会話、実在人物の発言ではないことを常時明示。好感度で段階解放し、既読は会話ごとのビットとして保存します。

IndexedDBでGP・カード・好感度・チャット・学習記録・途中回答・ログイン履歴・設定を保存し、トランザクション内で最新データを読んで更新します。直前の正常なセーブも保持。JSON復元は確認とスキーマ・参照検証を通し、復旧不能なデータを暗黙に新規データで上書きしません。

## 教材の追加検査・修正

- `mode-overrides.json` に600問分の空欄位置・正解・誤答3つ・HARD用単語3つを明示。
- HARDのダミー語は教材中に存在する実際の英単語から選び、正解トークンと重複させません。
- 文法と和訳を含めてEASYの一意性を検討。意味・時制が異なる文としては成立する選択肢もあります。
- not as / not so、関係代名詞that / who / which、間接話法の時制など、自然な別解を誤答候補から除外して登録。
- 短縮形と一部の副詞節順変更を明示的な別解に追加。未登録の任意の同義表現まで自動判定するものではありません。
- `borrow` の「借りる」の和訳、`Are we early?` の和訳、結果用法のto不定詞、過去完了の個別解説を修正。CSVの対応箇所も更新。
- 全600問に対する自動整合性・解答検証は完了。独立した英語母語話者・教育専門家による最終監修済みとはしていません。
