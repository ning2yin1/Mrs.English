# 音声と画像の登録手順

既存音声は今回未添付。実聴・分類は未完了です。テンプレートは空欄で納品し、実在しないファイル参照を登録しません。

1. 既存コードと音声を確認し、member_id、voice_id、実際のaudio_path、対応photo_pathを1行ずつ登録。
2. 実聴した台詞と意味をtranscript/meaning_classへ。success（祝福）、encourage（励まし）、apology（謝罪）、neutral、unknownへ分類。ファイル名だけで意味を決めない。
3. 満点はsuccessまたは文脈確認済みneutralだけ。apologyは満点へ割り当てない。encourageは低評価向け。unknownは無効。S評価でも満点とは限らないのでrequires_perfectを別に判定。
4. 同じ推しの写真と音声だけを組にする。対応がない音声は使用しない。写真の顔位置face_x/face_yを百分率で実測し保存。
5. 再生可能な候補がない/ブラウザが再生を拒否した場合は、音声なしで正常に結果を出す。もう一度聞くボタンは追加しない。最初のユーザー操作時に音声環境を準備するが、自動再生を保証した表現はしない。
6. 既存保存済みのボイス解放条件や所持カード制限がある場合はそれを維持する。

review_status=verifiedの行だけを本番候補へ。既存データ・写真がないためこのキット単独で意味の対応検証を終えたとは扱わないこと。
